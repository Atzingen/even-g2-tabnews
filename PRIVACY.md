# Política de Privacidade — TabNews para Even G2

Última atualização: 9 de setembro de 2026.

O app **TabNews** para os óculos Even G2 (identificador `com.atzingen.tabnews`) é mantido por Gustavo von Atzingen.

## Dados coletados

Nenhum. O app não coleta, armazena nem transmite dados pessoais, identificadores do aparelho, localização, áudio ou informações de uso.

## Conexões de rede

A única conexão de rede do app é com a API pública do TabNews, em `https://www.tabnews.com.br`, usada exclusivamente para baixar títulos e textos de posts publicados. Essas requisições são anônimas: não incluem conta, token, cookie ou qualquer dado do usuário. O TabNews pode registrar o endereço IP do celular como qualquer servidor web; consulte a política do TabNews em https://www.tabnews.com.br/termos-de-uso.

## Permissões

- `network` — necessária para acessar a API pública do TabNews. Nenhum outro domínio é acessado.

O app não pede microfone, câmera, localização, álbum ou qualquer outra permissão.

## Armazenamento

O app não grava dados no celular nem nos óculos além do cache temporário do próprio WebView, que é apagado pelo sistema.

## Terceiros

Não há analytics, anúncios ou rastreadores adicionados pelo app. O app utiliza o SDK Even Hub para se comunicar com a plataforma Even Realities.

# Privacy Policy — TabNews for Even G2

Last updated: September 9, 2026.

The **TabNews** app for Even G2 glasses (package `com.atzingen.tabnews`) is maintained by Gustavo von Atzingen.

## Data collected

None. The app does not collect, store or transmit personal data, device identifiers, location, audio or usage information.

## Network connections

The app's only network connection is to the public TabNews API at `https://www.tabnews.com.br`, used solely to download titles and bodies of published posts. Requests are anonymous: no account, token, cookie or user data is sent. TabNews may log the phone's IP address as any web server does; see https://www.tabnews.com.br/termos-de-uso.

## Permissions

- `network` — required to reach the public TabNews API. No other domain is accessed.

The app does not request microphone, camera, location, album or any other permission.

## Storage

The app stores nothing on the phone or glasses beyond the WebView's temporary cache, which the system clears.

## Third parties

The app includes no analytics, ads or tracking tools. It uses the Even Hub SDK to communicate with the Even Realities platform.
